# 贪吃蛇游戏 (Snake Game)

一个用HTML、CSS和JavaScript实现的经典贪吃蛇游戏。

## 游戏说明

这是一个经典的贪吃蛇游戏，玩家控制一条蛇在游戏区域内移动，吃掉食物来增长身体并获得分数。

### 游戏规则

- 使用方向键控制蛇的移动方向
- 吃到红色食物，蛇身会增长，得分+10
- 撞到墙壁或自己的身体，游戏结束
- 最高分会自动保存在浏览器中

### 操作说明

- **方向键 (↑ ↓ ← →)**: 控制蛇的移动方向
- **空格键**: 开始游戏或重新开始

## 如何运行

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器运行：
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 或使用 Node.js
   npx http-server
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 游戏特性

- 🎮 流畅的游戏体验
- 📱 响应式设计，支持不同屏幕尺寸
- 🏆 自动保存最高分记录
- 🎨 美观的界面设计
- 🌐 中文界面，易于理解

## 技术栈

- HTML5 Canvas
- CSS3
- 原生 JavaScript (无依赖)

## 开发

本游戏使用纯前端技术开发，无需任何后端服务或外部依赖。所有代码都在客户端运行。
